# Data Analyzer & Information Processing Skill

## Summary
Equips your agent with a structured framework for analyzing datasets, summarizing complex information into clean tables, identifying key insights, and formatting outputs for clarity.

---

## When to Use
- Processing and analyzing structured data, logs, or raw text datasets.
- Extracting key patterns, trends, or statistical insights.
- Converting unstructured text or documents into structured markdown tables or bullet points.
- Cleaning, formatting, or organizing data inputs.

---

## Workflow & Methodology

### Phase 1: Data Ingestion & Scope Analysis
1. **Understand Data Structure:** Identify rows, columns, variables, or text hierarchies provided in the input.
2. **Define Analytical Goals:** Determine what the user wants to discover, summarize, or extract.

### Phase 2: Processing & Transformation
1. **Extract Core Metrics:** Pull out key numbers, totals, categories, or thematic insights.
2. **Structure the Findings:** Organize data logically using Markdown tables, structured lists, or categorized summaries for maximum readability.

### Phase 3: Insights & Validation
1. **Highlight Key Takeaways:** Provide a brief executive summary of the most important patterns or anomalies.
2. **Verify Accuracy:** Cross-check computed summaries or extracted points against the raw input.

---

## Output Format Guidelines
- **Use Tables for Comparisons:** Present multi-variable data in clean Markdown tables.
- **Keep Summaries Scannable:** Use bold text for key metrics and bullet points for detailed breakdowns.
