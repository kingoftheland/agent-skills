# Agent Skills

Reusable skill playbooks for AI agents. Each folder is one skill with a `SKILL.md` that tells an agent how to do the job.

## Skills

| Skill | What it does |
|---|---|
| `agentic-bug-hunter-SKILL.md` | Hunt web3 bug bounties: scope, payout, 7-Question Gate, PoC rules |
| `expert-workflow-SKILL.md` | Complex work in 4 phases: decompose → plan → execute → self-validate |
| `data-analyzer-SKILL.md` | Analyze structured data, extract insights, build clean tables |

## How to use

Point your agent at the `SKILL.md` of the skill you need and tell it to follow it. Skills are plain Markdown — no install step.
